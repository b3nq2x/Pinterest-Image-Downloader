<h3>Pinterest Image Downloader</h3>

<h3>INSTALL :</h3>
pip install requests<br>
pip install playwright<br>
python -m playwright install<br>
<br>
1. Copy dan paste file cookie dari <a href='https://github.com/b3nq2x/Pinterest-Login'>Pinterest Login</a> ke folder utama.<br>
2. Jalankan <b>run.py</b><br>
3. File gambar akan tersimpan di folder <b>\Gambar</b><br>
4. Path gambar akan tersimpan di file Gambar.txt<br>
